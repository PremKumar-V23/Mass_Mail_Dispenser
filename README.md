# 📧 Mass Mail Dispatcher System

## 📌 Overview

This project is a web-based Mass Mail Dispatcher developed during my internship at Exposys Data Labs. It allows users to send bulk emails efficiently while tracking email status and previewing content before sending.

---

## ❓ Problem Statement

Sending bulk emails manually is time-consuming and error-prone. There is also no easy way to verify email content or track delivery status before sending.

---

## 💡 Solution

This system automates the process of sending bulk emails and provides additional features such as:

* Email preview before sending
* Email validation
* Status tracking for each email

---

## ⚙️ Tech Stack

* HTML
* CSS
* JavaScript

---

## ✨ Features

* 📤 Send bulk emails using CSV data
* ✅ Email validation (valid & invalid separation)
* 👁️ Email preview before sending
* 📊 Email status tracking
* 🧾 Organized email list display

---

## 🧠 How It Works

1. Upload a CSV file containing email addresses
2. System filters valid and invalid emails
3. User previews the email content
4. Emails are sent in bulk
5. Status of each email is displayed

---

## 📊 Results / Output

* Successfully sends bulk emails
* Separates valid and invalid email addresses
* Displays email sending status clearly
